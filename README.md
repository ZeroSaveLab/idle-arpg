# Idle ARPG V2

Protótipo de navegador com câmera top-down e mapas independentes.

## Implementado
- Menu superior: Mapas / Inventário / Personagem
- Floresta Inicial (nível 1–10)
- Ruínas Abandonadas (nível 11–20)
- Bloqueio por nível
- Troca de mapa independente
- Personagem visível
- Combate automático
- XP, level, ouro e kills
- Loot e auto-equip simples
- Inventário
- Ficha de personagem
- Salvamento local
- Interface responsiva

## Direção visual
Sem pixel art. O código atual usa formas vetoriais desenhadas no Canvas como placeholder para não depender de assets externos. A pasta `assets/` já está pronta para receber sprites e mapas licenciados.
