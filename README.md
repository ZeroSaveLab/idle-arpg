# Idle ARPG — V3 (Lords Of Pain Demo Assets)

Esta versão usa os PNGs reais da demo que o usuário forneceu, em vez dos placeholders vetoriais.

Conteúdo usado da demo:
- Warrior (idle/walk)
- Skeleton (walk)
- Ground Stone
- Rocks / Mushrooms
- UI assets
- Gold drops podem ser usados em seguida

Mecânicas:
- câmera isométrica/top-down
- combate automático
- mapas independentes
- mapa 1 nível 1–10
- mapa 2 nível 11–20
- inventário
- personagem
- loot e auto-equip simples
- XP / level / ouro / kills
- save em localStorage

A demo fornecida contém apenas `Ground Stone` como elemento de environment no Asset Index (DEMO), portanto os dois primeiros mapas usam o mesmo chão com ambientação/overlay diferente enquanto a lógica de mapas já fica pronta.
